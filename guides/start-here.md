# Start here

[← Main guide](../README.md)

Choose the route closest to your background. The resource list is a menu, not a checklist: you can learn deeper mathematics and specialist methods alongside the work that needs them.

## If you come from biology

Start with [practical programming](foundations.md#programming) in one language. R is a natural choice for the RNA-seq starter; Python is used in the structure and workflow starters. Learn sample metadata and [experimental design](foundations.md#statistics), then complete one small project.

## If you come from computing

Start with [biological data and formats](foundations.md#biological-data). Learn how the assay works, what an independent biological sample is, and how controls and confounding affect interpretation. Reproduce a documented analysis before extending it.

## If you are still exploring

Inspect a [protein structure](../projects/protein-structure/README.md), or try an introductory [Galaxy tutorial](https://training.galaxyproject.org/). Notice which biological questions interest you, then choose a learning track.

## Your learning map

![Learning map connecting foundations, structural bioinformatics, omics, shared workflows and AI, and practical projects.](../site/assets/roadmap.svg)

1. Choose a biological question.
2. Learn the next necessary skill.
3. Reproduce a small example and inspect the outputs.
4. Explain what you found, what you changed, and what remains uncertain.
5. Share the data accession, software versions, parameters, and rerun instructions.

## Read the labels

- **Beginner:** an accessible entry point; check the specific prerequisites.
- **Intermediate:** some coding or biological analysis experience is assumed.
- **Advanced:** build the preceding scientific, statistical, and computational context first.

You do not need both R and Python, both workflow engines, or a complete machine-learning course before attempting a first analysis. Pick one route and add skills as needed.
