# Learn by doing

[← Main guide](../README.md)

These small examples connect a biological or computational question to inputs, outputs, and interpretation. They are teaching projects rather than production pipelines.

| Project | Start here if… | What you will make |
| --- | --- | --- |
| [Your first RNA-seq comparison](rna-seq/README.md) | You know basic R and want to analyze gene counts. | A design-aware comparison, QC plots, and a results table. |
| [Read your first protein structure](protein-structure/README.md) | You know basic Python and protein biology. | A structure report, a residue table, and interpretation notes. |
| [One analysis, two workflow engines](workflow-basics/README.md) | You can run a Python script and want to learn workflows. | The same verified output from a script and a workflow engine. |

Follow a project from a fresh session and record your software versions. The RNA-seq and protein-structure examples need external packages and initial network access. The plain Python workflow example uses only the standard library and includes its tiny synthetic input.

Each project describes its expected outputs and interpretation limits. See [VALIDATION.md](../VALIDATION.md) for the checks performed during this update; do not assume every scientific runtime was available.
